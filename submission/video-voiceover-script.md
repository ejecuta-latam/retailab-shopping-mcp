# shopping-mcp Walkthrough Voiceover

This script is aligned to the normal-motion autoplay at `/walkthrough?record=1`. It runs for about one minute at a calm 125–135 words per minute.

## Recording setup

1. Open `http://127.0.0.1:4321/walkthrough?record=1`.
2. Start screen recording, then reload the page.
3. Begin speaking immediately when the title card appears.
4. Read only the quoted text below. The notes in parentheses are visual cues, not narration.
5. Pronounce `shopping-mcp` as “shopping M-C-P,” `open_ui` as “open U-I,” and the URL as “shopping dot ejecuta dot lat slash demo.”

*(The shopping-mcp title card is visible.)*
